

# Website Analytics and Search Engine Tools

## Analytics tools
- What Website visitors do 

| Tool                | Purpose                                          | Free?                   |
| ------------------- | ------------------------------------------------ | ----------------------- |
| Google Analytics 4  | Visitor tracking, traffic sources, user behavior | ✅ Yes                   |
| Microsoft Clarity   | Session recordings, heatmaps, user interactions  | ✅ Yes                   |
| Yandex Metrica      | Traffic analytics and visitor behavior           | ✅ Yes                   |
| Plausible Analytics | Privacy-focused website analytics                | ❌ Paid                  |
| Matomo              | Self-hosted or cloud analytics                   | Free self-hosted option |



## Website Indexing  : find my website
- Search engine webmaster tools
- These help you understand how search engines discover and display your website.

| Tool                           | Search engine | Purpose                                        |
| ------------------------------ | ------------- | ---------------------------------------------- |
| Google Search Console          | Google        | Indexing, search traffic, keywords, SEO issues |
| Bing Webmaster Tools           | Bing          | Indexing, search performance, SEO reports      |
| Yandex Webmaster               | Yandex        | Indexing and search visibility                 |
| Baidu Search Resource Platform | Baidu         | Search visibility, primarily China             |
| Naver Search Advisor           | Naver         | Search visibility, primarily South Korea       |


## Submit Your Website to Other Search Engines
| Search engine | Webmaster tool                                                                          | Priority                      |
| ------------- | --------------------------------------------------------------------------------------- | ----------------------------- |
| Google        | [Google Search Console](https://search.google.com/search-console/about)                 | ⭐ Essential                   |
| Bing          | [Bing Webmaster Tools](https://www.bing.com/webmasters/about)                           | ⭐ Essential                   |
| Yandex        | [Yandex Webmaster](https://webmaster.yandex.com/)                                       | Optional                      |
| Naver         | [Naver Search Advisor](https://searchadvisor.naver.com/)                                | Optional                      |
| Baidu         | [Baidu Search Resource Platform](https://ziyuan.baidu.com/)                             | Optional                      |
| Seznam        | [Seznam Webmaster](https://search.seznam.cz/)                                           | Optional                      |
| DuckDuckGo    | No separate general webmaster console                                                   | No direct submission          |
| Brave Search  | [Bing Webmaster Tools](https://www.bing.com/webmasters/about) and general SEO practices | No standard dedicated console |
| Ecosia        | Bing-based discovery and indexing pathways                                              | No standard dedicated console |
